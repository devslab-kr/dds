# @devslab/dds-table

TanStack Table 기반 DDS 데이터 테이블 패키지. 단일 `DataTable` 컴포넌트와
이를 기술하는 `Column<T>`·`DataTableLabels` 타입을 제공한다 — 정렬, 좁은
컬럼 접기, 페이징은 내부에서 처리하므로 소비자는 데이터와 컬럼 설명만
넘기면 된다.

```sh
pnpm add @devslab/dds-table
```

전체 API 문서(`Column<T>` 필드, `sort` union, 페이징, 컬럼 접기, 필수
접근성 라벨)는 구현이 들어온 뒤 이어서 작성한다.
