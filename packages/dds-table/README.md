# @devslab/dds-table

Declarative data table for DDS, built on TanStack Table. Provides a single
`DataTable` component plus the `Column<T>` and `DataTableLabels` types used
to describe it — sorting, folding narrow columns, and paging are handled
internally so consumers only supply data and column descriptors.

```sh
pnpm add @devslab/dds-table
```

Full API documentation (the `Column<T>` fields, the `sort` union, paging,
column folding, and the required accessibility labels) follows once the
implementation lands.
