These third-party provider marks come from the existing qoqo and Qooroo asset sets, with source, transformation and SHA-256 recorded in `provenance.json`. The providers own the marks and their brand rules apply. Including artwork does not establish provider-console setup, app verification or brand approval. The GitHub Octicons license for `github-symbol.svg` is included.

Import `@devslab-kr/dds-auth/styles.css` to load the packaged marks for an explicit `providerOrder`: Google, Kakao, Naver, LINE, Microsoft, LinkedIn, GitHub, Discord, Figma, Notion, X, Slack and Zoom. X uses the light-on-dark variant beneath a `data-theme="dark"` element. GitLab stays text only. Apple, Facebook and WeChat have no packaged mark; the product can supply provider-approved controls or artwork.

Use `providerIcons` to override a packaged mark or pass `null` to suppress it. You can copy the exported image files to the app's public asset directory or use bundler URL imports. Preserve the original colors and aspect ratios and use provider-specific controls when mandated. See the [LINE sign-in button guide](https://developers.line.biz/en/docs/line-login/login-button/), [Apple sign-in guidance](https://developer.apple.com/design/human-interface-guidelines/sign-in-with-apple), and the linked sources in the provenance file for each mark. The package uses relative CSS URLs; the bundler controls asset routing and inlining.
