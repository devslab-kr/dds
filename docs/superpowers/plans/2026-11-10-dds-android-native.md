# DDS Android Native 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Android token values, a Compose theme and motion helpers generated from `tokens/*.json`, installable from a local Maven repository as `kr.devslab:dds-android-tokens` and `kr.devslab:dds-compose` 0.1.0.

**Architecture:** A Node generator reads the same token graph the web build reads and writes committed Kotlin constants and XML resources; a Node test regenerates and compares byte-for-byte. A Gradle project under `android/` holds a values-only library, a Compose library that maps the values onto Material3, and a catalog app used for visual checks.

**Tech Stack:** Node 20+ (`node --test`), Kotlin 2.2.20, AGP 8.13.0, Gradle 8.14.3, Compose BOM 2026.01.00, Material3, `com.vanniktech.maven.publish`.

**Spec:** `docs/superpowers/specs/2026-11-10-dds-android-native-design.ko.md`

Owner decisions (2026-11-10): two artifacts; Maven Central with `android-v*` tags and an independent version starting at 0.1.0; values + theme + motion + guide first, components in 0.2.0; minSdk 26; filled brand face is `bg.brand` with `text.on-brand` in both themes.

## Global Constraints

- minSdk 26, compileSdk 36, JVM target 17.
- Group `kr.devslab`; Kotlin packages `kr.devslab.dds.tokens`, `kr.devslab.dds.compose`.
- No hex literal and no `Color(0x…)` in `android/**` outside `android/dds-tokens/src/main/**/generated/` and `res/values*/dds_tokens.xml`.
- No user-facing string inside the libraries; every label is a parameter.
- No overshoot or spring in any helper. Durations and easings come only from generated constants.
- Generated files carry the header `Generated by scripts/generate-android-tokens.mjs — do not edit.`
- Documents ship as `*.md` + `*.ko.md` pairs. No push, PR, tag or publish to a remote.
- adb and Gradle device commands always name the emulator serial; never touch `emulator-5554`, `emulator-5570` or the attached phone.

## Review Focus

1. A product brand whose on-brand text fails 4.5:1 on its filled face → `DdsBrand` construction fails with the measured ratio (Task 4 test).
2. System animator scale 0 → screen shift, stagger and logo travel are skipped; state changes still complete (Task 5 test + catalog capture).
3. Activity recreated (rotation, process restore) → the splash handoff does not replay (Task 5 test).
4. Font scale 200% → nothing clips in the catalog; control heights are minimums (Task 6 capture).
5. A token with an unknown `$type`, or `native.json` edited without regenerating → generator throws / drift test fails (Task 1 and 2 tests).
