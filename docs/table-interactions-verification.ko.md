## 범위

- 선택 옵션으로 컬럼 드래그·키보드 리사이즈와 전체 너비 초기화 제공.
- 기존 클라이언트 정렬과 서버 정렬 설명을 유지하면서 제어형 서버 정렬 요청 추가.
- ID 기반 행 선택과 키보드 선택 제공. 행 내부 버튼·링크·입력 요소 동작 유지.
- 업무 처리·실제 조회·내보내기·분석 전송은 소비 앱에서 연결.
- FM 적용, npm 게시, 운영 배포는 이 변경의 완료 항목이 아님.

## CI에서 발견한 빌드 순서 문제

PR 최초 CI `37756567825`는 카나리의 토큰/CSS import에 필요한 dist 파일이 아직 생성되지 않아 실패했다. 로컬 전체 빌드는 이미 foundation 산출물이 있어 이 문제가 드러나지 않았다. 카나리 빌드 명령이 토큰과 CSS 생산자를 먼저 빌드하도록 의존성을 명시하고 새 커밋의 전체 CI로 재검증한다. 실패 검사를 생략하거나 CSS import를 제거하지 않는다.

`FM 업무 페이지 → FM DataGrid 어댑터 → DDS DataTable → TanStack Table`.
공통 상호작용을 FM에서 다시 구현하지 않고, 콜백에서 서버 조회·업무 처리·분석 이벤트를 연결한다.
